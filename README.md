# Mas

## A full-stack SEC fantasy football app built with FastAPI and React

This application allows leagues of six teams to compete in a short fantasy football season taking place towards the end of the year when games matter the most and excitement is at it's peak in the best conference in all of college football

## Tech stack
- PostgreSQL database with alembic migrations and a docker file for the development stage
- FastAPI backend gathering data from the database as well as the College Football Data API for frontend fetching and cron jobs
- React frontend to fetch data from the backend and display it to the user
